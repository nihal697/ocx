# OCX — archived

> **OCX is discontinued.** I found a better alternative and stopped maintaining
> this fork. Nothing here will be updated further — no new releases, no fixes.

**Use this instead: [OpenChamber](https://github.com/openchamber/openchamber)**
— the richer open-source interface for the [opencode](https://github.com/sst/opencode)
AI agent (desktop, web, VS Code, iOS, Android):

- Project: [github.com/openchamber/openchamber](https://github.com/openchamber/openchamber)
- Site & docs: [openchamber.dev](https://openchamber.dev/)
- Android app: [openchamber-android](https://github.com/michael-farah/openchamber-android)
  (native wrapper — APKs in [OpenChamber releases](https://github.com/openchamber/openchamber/releases))

## Last OCX release

The final build is **v0.4.25** (`com.ocx.app`):
[github.com/nihal697/ocx/releases/latest](https://github.com/nihal697/ocx/releases/latest).
It keeps working against your own opencode server — it just won't evolve.

## History

OCX was a fork of [ncend/opencode-mobile](https://github.com/ncend/opencode-mobile)
(itself from [dzianisv/opencode-mobile](https://github.com/dzianisv/opencode-mobile)),
connecting to an [opencode](https://github.com/sst/opencode) server you run yourself.
Thank you to the upstream developers — if OCX was useful, consider sponsoring them:
[github.com/sponsors/VibeTechnologies](https://github.com/sponsors/VibeTechnologies).
