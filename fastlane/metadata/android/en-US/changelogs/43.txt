v0.4.16 — OCX rebrand + catalog scoping, session errors, keyboard + voice fixes

• App is now OCX (package com.ocx.app): independent release stream, clean install alongside the upstream app.
• Sessions now load the agent catalog per directory, so the right agents show for each project.
• Session errors now appear as a dismissible banner instead of failing silently.
• Chat connects faster: message streaming starts without waiting for metadata.
• Android keyboard no longer covers the chat input; the view scrolls to keep it visible.
• Stopping voice input no longer shows a false error.
